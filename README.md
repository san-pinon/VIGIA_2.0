VIGIA_2.0
=========
Suite of control software for Version 2.0 of the VIGIA system.

<h1 align="center">
    <b>NOTE: THIS PACKAGE IS A WORK IN PROGRESS</b>
</h1>

Installation
------------
Note: Installation requires an internet connection.

Clone the repository:

```console
git clone https://github.com/fvasconez/VIGIA_2.0
cd VIGIA_2.0
```

We recommend using ``uv``, a fast Python package and project manager, to set up an isolated virtual environment:

```console
uv venv --python=3.12
source .venv/bin/activate
uv pip install .
```
